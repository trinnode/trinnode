## Selected Work

> A focused selection of personal projects I designed and shipped end to end. No forks, no contributed PRs.

| Project | What it does | Stack |
| :-- | :-- | :-- |
| **[VERIDAQ](https://github.com/trinnode/veridaq-official)** · [live](https://veridaq-official.vercel.app) | Zero-knowledge academic credential verification. Universities issue on their own backend; employers verify claims like *"CGPA above 3.5"* without ever seeing student data. A single 32-byte commitment touches Base L2. | Base · SnarkJS · Next.js · TypeScript |
| **[ClearScope](https://github.com/trinnode/clearscope)** | Compliance proofs without disclosure on Midnight Network — holder wallet, verifier dashboard, issuer portal and governance registry, with ZK eligibility checks for age, KYC and jurisdiction. Apache-2.0, CI-gated. | Midnight · Compact · TypeScript |
| **[AfriHealth Ledger](https://github.com/trinnode/AfriHealthv2)** · [live](https://afri-healthv2-frontend-9tth.vercel.app) | Hedera-native healthcare and insurance platform: patient-controlled consent, itemized billing with AI policy checks, and an on-ledger community insurance pool. Modular EIP-2535 Diamond with Consent, Billing, InsurancePool and Token facets. | Hedera · Solidity · HTS · Diamond |
| **[CPPay](https://github.com/trinnode/CP-Pay-SC)** | Non-custodial account-abstraction wallet on Lisk L2 — gasless one-tap payments via session keys, social recovery with guardians, and on-chain swaps. Diamond standard + ERC-4337, 100% test coverage. | Lisk L2 · ERC-4337 · Diamond |
| **[Anglican Schools](https://github.com/trinnode/anglican-schools)** · [live](https://anglican-schools.vercel.app) | Production multi-branch school management for the Nigerian system — token-based staff access across 11 roles, a drag-and-drop report-card builder, fees, waivers and a full audit trail. | Next.js 16 · React 19 · Prisma |
| **[Votara](https://github.com/trinnode/votara)** · [live](https://votarahq.vercel.app) | Multi-tenant voting platform for contests — live leaderboards, contestant profiles, 3D tilt UI and Flutterwave OAuth 2.0 payments. | Next.js 16 · Prisma · Flutterwave |
| **[BExtDetect](https://github.com/trinnode/BExtDetect)** | Chrome-extension malware scanner — static manifest and code analysis (permissions, suspicious patterns, entropy) fused with a sandboxed headless-browser run into a single risk score. | Python · Node.js · Chromium |
| **[Phishing Domain Detection](https://github.com/trinnode/phishing-detection)** | Research framework comparing Random Forest vs XGBoost over lexical and structural URL features. Flask REST API plus a full training pipeline. FUT Minna chapter-4 implementation. | Python · scikit-learn · Flask |
